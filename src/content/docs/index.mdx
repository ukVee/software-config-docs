soft-fig is one tool for the files that describe your machine: a **memory
garden**, a **dotfile manager**, an **encryption-at-rest store**, and a
**version control system** — sharing one config and one CLI, instead of four
tools stitched together.

:::caution[Work in progress]
soft-fig is a single-author work in progress, not a released tool — and these
docs are being written section by section, so most pages are still stubs. The
[code repository](https://github.com/ukVee/software-config-garden) is the
current source of truth.
:::
